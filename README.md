# אני לא אייפון

ווידג'ט בסגנון תיבת "לא רובוט", שבודק אם הגולש באייפון. הבדיקה רצה בדפדפן של הגולש לפי `navigator.userAgent`, ולא נשלח שום מידע לשרת.

## שימוש

```html
<div data-not-an-iphone></div>
<script src="not-an-iphone.js"></script>
```

כל אלמנט עם `data-not-an-iphone` הופך לווידג'ט. הסקריפט עובד גם לפני וגם אחרי סוף הדף.

## בדיקה מקומית

```bash
npm test
```

לפתיחת הדמו, פתחו את `demo.html` בדפדפן. הוספת `?click` לכתובת מדמה לחיצה אחת על התיבה.

## מה הווידג'ט עושה

- לחיצה על התיבה מציגה "בודק..." ואחר כך את התוצאה.
- באייפון: האימות נכשל. בכל מכשיר אחר: האימות עובר. iPad ו-Mac לא נחשבים לאייפון.
- הבדיקה מבוססת על ה-user agent, וגולש יכול לשנות אותו. זה ווידג'ט בדיחה, לא מנגנון אבטחה.
